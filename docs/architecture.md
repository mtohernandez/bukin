The structure is separated into four distinct hierarchical layers: an :app module acting as the system glue for DI and root navigation; a :core layer containing isolated, stateless technical engines like network, database, and design systems; a pure Kotlin :domain layer for app-wide business logic; and a :features layer where each business capability is split into a lightweight :public-api contract module and a completely hidden :implementation module. According to official Google architecture guidelines, this setup guarantees that feature modules can only interact through minimal, public interfaces via a strict top-down dependency flow, eliminating circular dependencies, restricting cross-feature imports, and keeping compilation times highly optimized across large engineering teams.
